# 📌 Project Overview

Bloom App is a modern meditation and wellness landing page application developed using React and Vite. The platform is designed with a calming user interface and elegant typography to create a peaceful digital experience for users interested in mindfulness and meditation.

The application includes multiple interactive sections such as testimonials, FAQ, meditation guidance, and app showcase areas that improve user engagement and usability.

The project is fully responsive and deployed live using Vercel.

# ⚙️ Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/Lavan0225/Bloom-App.git
```

---

## 2️⃣ Navigate to Project Folder

```bash
cd Bloom-App
```

---

## 3️⃣ Install Dependencies

```bash
npm install
```

---

## 4️⃣ Start Development Server

```bash
npm run dev
```
